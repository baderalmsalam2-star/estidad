# ميزة التسميع الصوتي مع التدقيق التجويدي
### مواصفات جاهزة لكلود ديزاين ثم كلود كود

---

## ١. الفكرة في سطر

يختار الطالب آيةً، يسمّعها بصوته، ثم يُسأل عن **أحكام التجويد الواردة في هذه الآية بعينها**، ويستطيع إعادة سماع تسجيله أثناء الإجابة.

**المبدأ الحاكم:** التطبيق **لا يحكم على التلاوة**. هو يوقظ أذن الطالب ويوجّه انتباهه. الحكم للطالب أو لشيخه.

⚠️ **لا تبنِ تصحيحاً آلياً للتجويد.** التقنيات المتاحة لا تحكم على الغنة والمدود والتفخيم حكماً موثوقاً، وخطأ التطبيق في تصحيح التلاوة يُثبِّت الخطأ في لسان الطالب وهو يحسب نفسه أتقن.

---

## ٢. تدفّق الشاشة

```
اختيار السورة  →  اختيار الآية (أو مقطع)
        ↓
شاشة التسميع:  [الآية بخط مصحفي]  ●  زر التسجيل
        ↓
انتهاء التسجيل  →  حفظ محلي
        ↓
شاشة التدقيق:
   ┌─────────────────────────────┐
   │  ▶ إعادة سماع تسجيلك        │  ← ثابت أعلى الشاشة طوال الأسئلة
   ├─────────────────────────────┤
   │  سؤال ١/٤                   │
   │  في قوله ﴿عَمَّ يَتَسَاءَلُونَ﴾  │
   │  ما حكم الميم في «عَمَّ»؟    │
   │  ○ إخفاء شفوي               │
   │  ● غُنّة مشدّدة حركتان      │
   │  ○ إظهار شفوي               │
   ├─────────────────────────────┤
   │  [أعد الاستماع]  [تحقّقت ✓] │
   └─────────────────────────────┘
        ↓
ملخّص: أحكام هذه الآية (٦) — تحقّقت من (٤)
        ↓
[أرسل التسجيل لشيخ]  ← اختياري
```

**الشرط الحاسم في التصميم:** زرّ إعادة السماع **ثابت ومرئي** طوال أسئلة التدقيق. الطالب يسمع ويجيب في آنٍ واحد — هذا هو جوهر الفائدة.

---

## ٣. نصّ القرآن — تنبيه لا يجوز تجاوزه

**لا تستخرج نصّ القرآن بالـOCR، ولا تكتبه يدوياً، ولا تولّده.**

النصّ يُجلَب من مصدر موثوق ويُخزَّن مرةً واحدة وقت البناء:
- مجمع الملك فهد لطباعة المصحف الشريف
- أو `quran.com` API (الرسم العثماني)
- أو `alquran.cloud` API

ويُحفظ مع كل آية: رقم السورة، رقم الآية، الرسم العثماني، ورسم الإملاء (للبحث).

**جزء عمّ ٥٦٤ آية فقط** — حجم صغير يُخزَّن كاملاً في التطبيق بلا اتصال.

## ٤. من أين تأتي أسئلة الآية؟

### مصدران، والدمج بينهما هو السرّ

**(أ) محرّك استنباط آليّ** — للأحكام التي تُستخرج من الرسم بيقين:

| الحكم | طريقة الاستنباط |
|---|---|
| النون الساكنة والتنوين | نون ساكنة أو تنوين + الحرف التالي → إظهار / إدغام / إقلاب / إخفاء |
| الميم الساكنة | ميم ساكنة + التالي (ب / م / غيرهما) |
| القلقلة | حرف من (قطب جد) ساكن أو موقوف عليه |
| المد المتصل | حرف مدّ + همزة في **نفس** الكلمة |
| المد المنفصل | حرف مدّ آخر الكلمة + همزة أول التالية |
| المد اللازم | حرف مدّ + سكون أصليّ |
| المد العارض | حرف مدّ + آخر الكلمة عند الوقف |
| لام لفظ الجلالة | حركة ما قبل «الله» → تفخيم / ترقيق |
| الغنة المشدّدة | نون أو ميم مشدّدة |
| اللام الشمسية والقمرية | «ال» + الحرف التالي |

**(ب) جدول استثناءات مُعدّ يدوياً** — للأحكام التي لا تُستنبط من الرسم:

- مواضع السكت الأربعة: ﴿عِوَجَا ۜ قَيِّمًا﴾، ﴿مَرْقَدِنَا ۜ هَٰذَا﴾، ﴿مَنْ ۜ رَاقٍ﴾، ﴿بَلْ ۜ رَانَ﴾
- الإظهار المطلق: الدنيا، بنيان، قنوان، صنوان
- الإمالة: ﴿مَجْرَاهَا﴾
- التسهيل: ﴿أَأَعْجَمِيٌّ﴾
- أوجه الأنفال والتوبة
- مواضع الوقف اللازم والممنوع والمعانقة

**هذا الجدول هو القيمة الحقيقية للتطبيق** — لأنه ما يُولَّد آلياً، ولا يوجد مجمَّعاً في مكان.

## ٥. مخطط بيانات الآية

```json
{
  "surah": 78,
  "ayah": 1,
  "uthmani": "عَمَّ يَتَسَآءَلُونَ",
  "rulings": [
    {
      "id": "78:1:r1",
      "word": "عَمَّ",
      "span": [0, 3],
      "rule": "غنة مشددة",
      "ruleKey": "ghunnah_mushaddadah",
      "source": "auto",
      "answer": "غُنّة بمقدار حركتين لأن الميم مشدّدة",
      "linkedQuestion": "TJW-014"
    },
    {
      "id": "78:1:r2",
      "word": "يَتَسَآءَلُونَ",
      "span": [4, 17],
      "rule": "مد واجب متصل",
      "ruleKey": "madd_muttasil",
      "source": "auto",
      "answer": "حرف المدّ والهمزة في كلمة واحدة، يُمدّ أربع أو خمس حركات",
      "linkedQuestion": "TJW-016"
    }
  ]
}
```

**`linkedQuestion`** يربط الحكم بسؤال في `01_tajweed.json` — فيقدر الطالب يفتح الشرح الكامل ومرجعه من غاية المريد بضغطة.

## ٦. توليد السؤال من الحكم

لكل `ruleKey` قالب سؤال واحد، والخيارات تُبنى من أحكام نفس العائلة (المشتّتات تكون قريبة لا بعيدة):

```
المدود      → متصل / منفصل / لازم / عارض / بدل
النون       → إظهار / إدغام بغنة / إدغام بغير غنة / إقلاب / إخفاء
الميم       → إخفاء شفوي / إدغام شفوي / إظهار شفوي
لام الجلالة → تفخيم / ترقيق
```

**مثال مولَّد:**
> في قوله ﴿يَتَسَآءَلُونَ﴾ — ما نوع المدّ؟
> ○ منفصل ● متصل ○ لازم ○ عارض للسكون

## ٧. التخزين — شرط بقاء التطبيق مجانياً

| البند | القرار |
|---|---|
| مكان التسجيل | **جهاز الطالب فقط** افتراضياً |
| الرفع | لا يحدث إلا عند ضغط «أرسل لشيخ» |
| الصيغة | Opus بمعدّل منخفض — الكلام لا يحتاج جودة موسيقية |
| التخزين السحابي | **Cloudflare R2** — الإخراج مجاني، وهو البند الذي يُفلِس تطبيقات الصوت |
| الحذف | تلقائي بعد ٣٠ يوماً للمرفوع |
| الرابط | موقّت الصلاحية، يُرسَل واتساب |

بهذه القيود يبقى مجانياً بلا سقف زمني — وهذا شرط الصدقة الجارية: **ألّا تتوقف لانقطاع تمويل**.

## ٨. الأذان — تطبيق نفس الفكرة بعائد أعلى

الأذان أسهل تقنياً وأثمن للمؤذّن:

- بروفة كاملة بألفاظه **الخمس عشرة** (وسبع عشرة للفجر بالتثويب)
- والإقامة بألفاظها **الإحدى عشرة**
- عدّاد للترسّل في الأذان والحَدْر في الإقامة
- قائمة تدقيق مبنية على **نصّ ميثاق المسجد** لا على اجتهاد
- مقارنة بتسجيل مؤذّن مرجعيّ

المصدر جاهز عندك: `07_meethaq.json` — الأسئلة MTH-012 و MTH-013 و MTH-014.

---

## ٩. ما لا يُبنى

- ❌ تصحيح آليّ للتجويد أو درجة نطق
- ❌ مقارنة صوتية آلية بتسجيل مرجعيّ
- ❌ رفع تلقائي للتسجيلات
- ❌ نصّ قرآن مستخرَج بالـOCR أو مكتوب يدوياً

---

## ١٠. ترتيب التنفيذ

1. جلب نصّ جزء عمّ من مصدر موثوق وتخزينه محلياً
2. محرّك الاستنباط الآليّ (يغطّي ~٨٥٪ من الأحكام)
3. شاشة التسجيل وإعادة السماع — التخزين محليّ
4. توليد الأسئلة وربطها بـ`01_tajweed.json`
5. جدول الاستثناءات اليدويّ
6. «أرسل لشيخ»
7. وحدة الأذان
