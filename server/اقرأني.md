# خادمُ الإحصاء

التطبيقُ يعمل بدونه. هذا الخادمُ **زائدٌ عليه لا شرطٌ فيه**: إن لم يُنشَر، أو
سقط، أو انقطعت الشبكة — عمل التطبيقُ كما هو ولم يرَ الطالبُ فرقاً. وكلُّ ما
يفعله أنّه يجمع الإجاباتِ **مجهولةً** ليُعرَف أيُّ سؤالٍ يُخطئ فيه الناس.

## ما يُخزَّن

| العمود | مثاله | لماذا |
|---|---|---|
| `device` | `3f2a…` (UUID) | رقمٌ عشوائيٌّ يولّده الجهاز لنفسه، لا يُطلَب من أحد |
| `question` | `GEN-FQH-018` | رقم السؤال |
| `score` | `0.6` | الدرجة من صفرٍ إلى واحد |
| `track` | `imam` | المسار |
| `at` | طابعٌ زمنيّ | متى |

**لا اسمَ، ولا هاتفَ، ولا بريدَ، ولا موضعَ، ولا عنوانَ IP يُخزَّن.** وإن مسح
الطالبُ بياناتِه من «حسابي» وُلِّد له معرِّفٌ جديد، فلا سبيلَ إلى وصلِ الجديد
بالقديم.

ولا تُعاد من `/stats` صفوفٌ فرديّةٌ البتّة — مجاميعُ فقط، ولا يظهر سؤالٌ أجاب
عنه أقلُّ من خمسةِ أجهزة: نسبةٌ من إجابةٍ واحدةٍ ليست إحصاءً. **وليس هذا الحدُّ
حمايةً للخصوصية** — كان مكتوباً أنّه كذلك فصُحِّح، وبيانُه في تعليقِ
`MIN_ANSWERS` في `worker.js`. والحدُّ يمنع
أن يُستدَلَّ على إجابةِ رجلٍ بعينه في مسجدٍ صغير.

## النشر — خمسُ خطوات

```bash
cd server
npx wrangler login

# ١) أنشئ القاعدة، وانسخ database_id الذي يطبعه إلى wrangler.toml
npx wrangler d1 create awqaf-stats

# ٢) ابنِ الجداول
npx wrangler d1 execute awqaf-stats --remote --file=schema.sql

# ٣) ضع مفتاح المشرف (كلمةٌ طويلةٌ تخترعها، لا تُرفَع إلى git)
npx wrangler secret put ADMIN_KEY

# ٤) ضع نطاق التطبيق في wrangler.toml ← ALLOWED_ORIGIN
#    مثال: https://baderalmsalam2-star.github.io

# ٥) انشر
npx wrangler deploy
```

يطبع الأمرُ الأخيرُ عنوانَ الخادم، نحو `https://awqaf-stats.<اسمك>.workers.dev`.
ضَعْه في `assets/js/sync.js` ← `SERVER`، وادفعِ التغيير.

## التحقّق

```bash
curl https://awqaf-stats.<اسمك>.workers.dev/health
# {"ok":true}

curl -H "x-admin-key: <مفتاحك>" https://awqaf-stats.<اسمك>.workers.dev/stats
```

## الكلفة

الطبقةُ المجانيةُ في Cloudflare: مائةُ ألفِ طلبٍ يومياً، وخمسةُ ملايينِ قراءةٍ
من D1. وبضعُ مئاتٍ من الطلاب لا تبلغ عُشرَ ذلك، فتبقى الكلفةُ صفراً — وهو قيدٌ
معماريٌّ في هذا المشروع لا تفصيلٌ عابر. ولا ينام الخادمُ ولا يبرد.
